# SpaceSpeeder
## 遊び方
制限時間以内でどれだけスコアをとれるかを競います。<br>
スコアは星を壊すことで加算され、高速で連続破壊するとボーナスが加算されます。<br>
制限時間はタイトル画面で変更可能です。<br>

WASD、Dパッド、アナログスティックで操作プレイヤーを操作します。<br>
星を破壊するたびにスピードが上がり、プレイヤーは小さくなります。<br>
Aボタンでパワーアップ。1秒だけプレイヤーが最初の大きさに戻ります。<br>
Bボタンでブレーキ。速度が遅くなり、操作しやすくなりますが、ステージ中は速度が上がらなくなります。<br>
